# BurnArc

**Know when Claude Code runs out — before it does.**

BurnArc shows your Claude Code 5-hour and weekly usage limits live in the Mac
menu bar, on iPhone, Apple Watch and widgets, with run-out projections, pace
markers and alerts. No account, no server.

- Website: https://lakpriya1s.github.io/burnarc/
- Download for Mac: https://github.com/lakpriya1s/burnarc/releases/latest/download/BurnArc.dmg
- Support: https://lakpriya1s.github.io/burnarc/support.html
- Privacy: https://lakpriya1s.github.io/burnarc/privacy.html

This repository hosts the website and the Mac releases. Found a bug or have an
idea? [Open an issue](https://github.com/lakpriya1s/burnarc/issues).
