Support

Setting up BurnArc takes a couple of minutes. If something doesn't look right, the fixes below cover the usual causes. Still stuck? Open an issue on GitHub.

Set up on your Mac

  1. Download the DMG, open it, and drag BurnArc into Applications. Open it — it lives in the menu bar.
  2. Open BurnArc's Settings from the menu bar and add your Claude Code profile folders, such as ~/.claude and ~/.claude-work. Choose the folder when asked so BurnArc can read it.
  3. Click Install Hook for each profile. Your existing status line keeps working.
  4. Send any message in Claude Code. Usage appears after Claude Code next redraws its status line.

Pair your iPhone and Apple Watch

  1. On the Mac: BurnArc → Settings → iPhones → Pair iPhone. A QR code and a code appear; they expire after 10 minutes.
  2. On the iPhone: open BurnArc and scan the code, or type it. Both devices must be on the same Wi-Fi.
  3. The Apple Watch app gets its data from your iPhone. Install it from the Watch app on your iPhone if it isn't there yet.

Troubleshooting

"Waiting for Claude Code" — the hook is installed but Claude Code hasn't redrawn its status line yet. Send a message in that profile.

"No plan limits reported" — Claude Code only reports 5-hour and weekly limits for Pro and Max plans.

"Hook not installed" — click Install Hook next to the profile in Settings. If you changed your status line by hand, click Update.

The iPhone can't find the Mac — check both are on the same Wi-Fi, BurnArc is running on the Mac, and Local Network access is allowed for BurnArc on the iPhone (Settings → Privacy & Security → Local Network).

No notifications — open BurnArc's Settings → Alerts. If it says notifications are off, use its button to open System Settings and allow them.

Numbers look old — usage updates whenever Claude Code redraws its status line. On iPhone, the app syncs while it's open on the same Wi-Fi; pull down to refresh.

Updating

Download the latest DMG and drag BurnArc into Applications to replace the old copy. Settings, accounts and pairings are kept.

Uninstalling

In BurnArc's Settings, click Uninstall for each profile — this puts your previous status line back. Then quit BurnArc and move it to the Trash.
